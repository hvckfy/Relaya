# Relaya — UI-спецификация (macOS)

Версия: 0.1 (черновик) · Охват: v0.1–v0.5 Mac-клиента. Relaya Cloud — отдельный продукт, здесь не описан.

## 1. Принципы

- **Нативность.** SwiftUI + AppKit, стандартные паттерны macOS: `NavigationSplitView`, toolbar, вкладки окна, sheets, popovers, Settings-окно, меню-бар. Никаких «веб-подобных» контролов.
- **`~/.ssh` — источник правды.** UI всегда показывает, *где* лежат данные (путь к ключу, строка в `~/.ssh/config`). Нет «своего хранилища».
- **Прозрачность изменений.** Любое изменение локальных файлов или сервера показывается заранее (diff/превью) и требует подтверждения.
- **Клавиатура прежде всего.** Всё доступно с клавиатуры, есть Command Palette (⌘K).
- **Системная тема.** Светлая/тёмная, accent color системы, SF Symbols, SF Pro / SF Mono.
- **Спокойный UI.** Минимум хрома, контент (терминал/экран) — главный.

## 2. Структура окна

Главное окно — трёхзонный layout:

```
┌──────────────────────────────────────────────────────────────┐
│ Toolbar: [sidebar] [◀▶]  Поиск/⌘K   [+ Хост] [⚡ Подключить]  │
├──────────────┬───────────────────────────────────────────────┤
│ Sidebar      │ Вкладки сессий:  prod-1 ×  │ db ×  │ +         │
│              ├───────────────────────────────────────────────┤
│ ★ Избранное  │                                               │
│ 🕘 Недавние   │        Контент: терминал / SFTP / VNC / RDP   │
│ ▾ Группы     │        или карточка хоста (если нет сессии)   │
│   ▸ prod     │                                               │
│   ▸ staging  │                                               │
│ 🔑 Ключи      │                                               │
│ ⇄ Туннели     │                                               │
│ 🤖 Агенты(MCP)│                                               │
├──────────────┴───────────────────────────────────────────────┤
│ Статус-бар: user@host · ключ ed25519 · 23 ms · ↑↓ · кодировка │
└──────────────────────────────────────────────────────────────┘
```

- Sidebar сворачивается (⌘⌃S). Ширина 220–320 pt.
- Вкладки — собственные вкладки внутри окна + поддержка нескольких окон (⌘N) и drag вкладки в отдельное окно.
- Split-view внутри вкладки (⌘D вертикально, ⌘⇧D горизонтально).

## 3. Экраны

### 3.1 Первый запуск (Onboarding)
3 шага, sheet поверх пустого окна:
1. **Приветствие** — «Ваши ключи живут в `~/.ssh`, а не у нас». Кнопка «Продолжить».
2. **Импорт** — найдено N хостов в `~/.ssh/config`, M ключей в `~/.ssh`. Список с чекбоксами (ничего не копируется — только чтение). Кнопка «Готово».
3. **Разрешения** — доступ к `~/.ssh` (если нужен), уведомления. Ссылка «Почему это нужно».

Пустое состояние (нет хостов): иллюстрация + «Добавить хост» / «Импортировать из `~/.ssh/config`».

### 3.2 Sidebar
- Разделы: Избранное, Недавние, Группы (папки, вложенность 1–2 уровня), Ключи, Туннели, Агенты (v0.5).
- Строка хоста: иконка протокола (SSH/VNC/RDP), алиас, подпись `user@hostname` серым, индикатор статуса (● подключён / ○ нет), бейдж 🔒 «вход по паролю» (подсказка про ключ), метка окружения (prod — красная точка).
- Контекстное меню: Подключить, Подключить в новом окне, Открыть SFTP, Изменить, Дублировать, Копировать `ssh`-команду, Показать в `~/.ssh/config`, Удалить.
- Drag & drop: хосты между группами, хост в область вкладок = подключить.

### 3.3 Карточка хоста (без активной сессии)
- Заголовок: алиас, `user@host:port`, метки.
- Большая кнопка «Подключить», вторичные: SFTP, Туннели.
- Блоки: Аутентификация (ключ / пароль), Последние подключения, Сниппеты для хоста, Заметки.
- Если вход по паролю — баннер: «Настроить вход по ключу» (см. 3.6).

### 3.4 Редактор хоста (sheet)
Поля сгруппированы в `Form`:
- **Основное:** Алиас (Host), Адрес (HostName), Порт, Пользователь, Группа, Метка окружения, Цвет.
- **Аутентификация:** Ключ (picker из `~/.ssh` + «Сгенерировать новый»), Пароль (Keychain), Агент-форвардинг.
- **Сеть:** ProxyJump (picker хостов), Keepalive, Сжатие.
- **Терминал:** Тема, шрифт, кодировка (наследуются из глобальных по умолчанию).
- **Протокол:** SSH / VNC / RDP (меняет набор полей).
- Внизу — свёрнутый блок «**Превью `~/.ssh/config`**» с diff изменений. Кнопки: Отмена / Сохранить.

### 3.5 Терминал
- SwiftTerm, полноразмерный, без лишних рамок.
- Над терминалом (скрывается): breadcrumbs `group › host`, кнопки SFTP, Туннели, Сниппеты, Split.
- Поиск в выводе (⌘F) — оверлей сверху справа.
- Состояния: Подключение (спиннер + этапы: DNS → TCP → хэндшейк → auth), Ошибка (сообщение + «Повторить»/«Изменить хост»/«Показать лог»), Разрыв (полупрозрачный оверлей + «Переподключить», авто-ретрай с таймером).
- Первое подключение: диалог проверки fingerprint (SHA256, тип ключа) — «Доверять» / «Отмена». Изменившийся fingerprint — красный предупреждающий диалог.
- Ввод пароля — sheet с чекбоксом «Сохранить в Keychain».

### 3.6 ⭐ Мастер «Настроить вход по ключу» (ключевая фича)
Триггер: успешный вход по паролю → ненавязчивый баннер сверху терминала: «Вы вошли по паролю. Настроить вход по ключу? [Настроить] [Не сейчас] [Не спрашивать для этого хоста]».

Sheet в 4 шага (степпер сверху):
1. **Ключ** — радио: «Создать новый ed25519» (рекомендуется) / «Использовать существующий» (picker). Поля: имя файла (`~/.ssh/id_ed25519_<host>`), комментарий, passphrase (опционально, с «Сохранить в Keychain»), чекбокс «Secure Enclave» (если доступно).
2. **Превью изменений** — три блока с diff:
   - Локально: новые файлы в `~/.ssh/` (права 600/644).
   - `~/.ssh/config`: добавляемые строки (`IdentityFile`, `UseKeychain`, `AddKeysToAgent`).
   - Сервер: строка, которая будет добавлена в `~/.ssh/authorized_keys`.
3. **Применение** — чек-лист с живыми статусами: ✓ ключ создан → ✓ config обновлён (бэкап `config.bak`) → ✓ ключ добавлен на сервер → ✓ проверка входа по ключу.
4. **Готово** — «Теперь вход по ключу». Опция-карточка (warning-стиль): «Отключить вход по паролю на сервере» → отдельное подтверждение с показом изменений `sshd_config` и предупреждением о риске блокировки.

Ошибки на любом шаге — откат с пояснением, что именно откатилось.

### 3.7 Ключи
- Таблица: Имя файла, Тип (ed25519/rsa/ecdsa/SE), Отпечаток, Комментарий, Passphrase (да/нет), В агенте (да/нет), Используется хостами (N).
- Тулбар: Сгенерировать, Импортировать, Показать в Finder.
- Детали ключа (inspector справа): публичный ключ (кнопка Копировать), список хостов, «Разложить на хосты…» (мультивыбор → тот же механизм, что 3.6), «Добавить в агент», «Удалить» (с предупреждением, какие хосты сломаются).

### 3.8 SFTP (v0.2)
- Двухпанельный режим: Локально | Удалённо (как Finder: список/колонки).
- Breadcrumbs пути, drag & drop между панелями и из Finder.
- Очередь передач — popover в тулбаре (прогресс, скорость, отмена).
- Быстрый просмотр (пробел), «Открыть в редакторе» с авто-аплоадом при сохранении.

### 3.9 Туннели / проброс портов (v0.2)
- Список: тип (L/R/D), `localPort → host:port`, через хост, статус-тоггл.
- Редактор — popover. Опция «Запускать при подключении к хосту».
- Активные туннели также в меню-баре.

### 3.10 Сниппеты (v0.2)
- Библиотека команд с переменными `{{name}}`, теги, привязка к хостам/группам.
- Вставка: ⌘⇧P в терминале → поиск → заполнение переменных → вставить / выполнить.
- Мультиотправка: выполнить на нескольких хостах (результаты по вкладкам).

### 3.11 VNC / RDP (v0.3–v0.4)
- Вкладка с удалённым экраном, режимы масштабирования: Fit / 1:1 / Retina.
- Плавающая панель (автоскрытие сверху): Ctrl-Alt-Del, клавиатура, буфер обмена, качество, полный экран, отключить.
- RDP-специфика в редакторе хоста: домен, разрешение, мультимонитор, звук, общие папки, RD Gateway.
- Статус качества соединения в статус-баре.

### 3.12 Агенты / MCP (v0.5)
- **Обзор:** статус локального MCP-сервера (вкл/выкл), путь к `relaya-mcp`, кнопки «Подключить к Claude Desktop / Cursor / …» (копирование конфига).
- **Права по хостам:** таблица хост × режим (Нет доступа / Только чтение / С подтверждением / Доверенный). Prod по умолчанию — «С подтверждением».
- **Подтверждение команды** — плавающее окно поверх всех (и уведомление): агент, хост (с меткой окружения), команда моноширинно, подсветка опасных частей; кнопки «Запретить» (по умолчанию) / «Разрешить один раз» / «Разрешить для сессии». Таймаут → запрет.
- **Журнал:** время, агент, хост, команда, решение, код выхода; фильтры, экспорт.
- Индикатор активности агента: значок 🤖 на вкладке/хосте, когда агент работает; опция «Показать сессию агента» в живой вкладке (read-only).

### 3.13 Command Palette (⌘K)
Единый поиск: хосты (подключить), действия (новый ключ, новый туннель), сниппеты, настройки. Префиксы: `>` действия, `@` хосты, `#` сниппеты.

### 3.14 Меню-бар (опционально)
Иконка в меню-баре: избранные хосты (быстрое подключение в Terminal.app или Relaya), активные туннели, статус MCP и ожидающие подтверждения.

### 3.15 Настройки (Settings-окно, вкладки)
- **Общие:** запуск при входе, меню-бар, поведение при закрытии окна.
- **Терминал:** тема (+ импорт iTerm-тем), шрифт, курсор, scrollback, звук, копирование по выделению, Option как Meta.
- **SSH:** путь к config, бэкап перед изменением, keepalive, предлагать настройку ключей (вкл/выкл).
- **Ключи:** тип по умолчанию, Secure Enclave, Keychain-интеграция.
- **Агенты (MCP):** режим по умолчанию, таймаут подтверждения, хранение журнала.
- **Обновления:** Sparkle, канал (stable/beta).

## 5. Визуальный язык

- Цвета: системные + семантические: `prod` — red, `staging` — orange, `dev` — green; опасные действия — red, подтверждения агента — accent.
- Иконки: SF Symbols (`terminal`, `key`, `display`, `network`, `arrow.left.arrow.right`, `cpu`/`sparkles` для агентов).
- Шрифты: SF Pro для UI, SF Mono / пользовательский для терминала.
- Материалы: sidebar — vibrancy, оверлеи — `.ultraThinMaterial`.
- Анимации — короткие (≤200 ms), уважать «Reduce Motion».
- Доступность: VoiceOver-лейблы, контраст AA, Dynamic Type там, где применимо.

## 6. Что нужно в набросках (приоритет)

1. Главное окно с sidebar + активный терминал (светлая и тёмная).
2. Мастер «Настроить вход по ключу» — все 4 шага.
3. Редактор хоста с превью `~/.ssh/config`.
4. Экран ключей с inspector.
5. Окно подтверждения команды агента.
6. Onboarding (3 шага) и пустое состояние.
7. SFTP, туннели, VNC/RDP — по одному экрану.
