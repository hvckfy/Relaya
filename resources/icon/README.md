# Relaya — исходники иконки

- `relaya-chain-r.blend` — сцена Blender с тремя замкнутыми звеньями, материалами, камерой и светом.
- `build_relaya.py` — воспроизводимое построение сцены и рендер. Запуск: `blender --background --factory-startup --python build_relaya.py`. Сохраняет сцену и PNG рядом со скриптом, перезаписывая одноимённые файлы.
- `relaya-chain-r-render.png` — исходный рендер Blender.
- `relaya-chain-r-icon.png` — обработанный через imagegen вариант.
- `relaya-icon.png`, `relaya-icon-v2.png`, `relaya-icon-r.png` — предыдущие варианты.

Промпт чистовой обработки: сохранить три замкнутых переплетённых звена в форме R и порядок перекрытий; сгладить металл, убрать резкие блики и заломы; приглушённый синий алюминий, серебряная диагональ, светлая скруглённая плитка macOS, без текста и неона.

Исходный .blend запоминает первоначальный путь рендера; перед ручным рендером выберите нужный Output Path. Python-скрипт использует собственную папку.
